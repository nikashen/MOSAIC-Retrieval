LEAKAGE-SAFE PROTOCOL

训练、选择与 Final 分离

Final 不是为了追逐 HEAD 重跑的分数；模型选择只读取 Dev，正式报告由互斥 audit 名称和哈希绑定。

  1. 01Train

    冻结 CLIP 主干；训练 projection、gate 或 temporal aggregator。

  2. 02Dev select

    选择 epoch / reranker alpha；方向性 R@10 门禁防止单侧退化。

  3. 03Commit & freeze

    记录配置、checkpoint 与输入哈希；保持 tracked worktree clean。

  4. 04One-time Final

    O_EXCL 抢占审计名称，计算配对指标并绑定报告 digest。
